# Dijkstra Landing Page

Dijkstra Landing Page is the public marketing site for Dijkstra. This document uses Simplified
Technical English. Sentences are short. Each sentence has one idea.

## What This Project Does

Dijkstra Landing Page introduces Dijkstra to a first-time visitor. It explains the mission and
points visitors toward sign-up and community links.

## Current Status

This project is minimal today.

- The `app` folder has only a layout file, a page file, a global stylesheet, and a favicon.
- No backend calls exist in this project.
- The `package.json` file still uses the name `my-v0-project`. This name is left over from a
  generated starting template and should be renamed.

## Technology

- Next.js
- TypeScript
- Tailwind CSS

## How It Connects To Other Dijkstra Projects

This project does not call any other Dijkstra service today. It is a standalone marketing page.
Future work may link this page to sign-up flows inside Dijkstra Web.

## How to Run It

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000` in your browser.

## Known Gaps

- The project name in `package.json` still reads `my-v0-project`.
- No links to other Dijkstra services exist yet.
- No dedicated content beyond the starting template has been confirmed in this evaluation.
